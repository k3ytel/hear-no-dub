# Hear No Dub

No dub? No problem. A client-side Fabric mod for Minecraft 26.3 that shows synced subtitles on your HUD for the video playing in your browser, so you can watch subbed anime while you play.

- Detects what's playing through Windows' media controls (Firefox, Chrome, Edge).
- Fetches English subtitles from OpenSubtitles (free API key needed), or uses your own `.srt` / `.ass` / `.vtt` files from `config/hear-no-dub/subs/`.
- Follows play, pause and seeking. Fix sync with `[` and `]`.

| Key | Action |
|---|---|
| `J` | Toggle subtitles |
| `[` / `]` | Subtitles earlier / later |
| `K` | Subtitle picker |

Windows only. Requires Fabric API and YetAnotherConfigLib; Mod Menu recommended.
